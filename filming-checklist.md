# Filming Checklist — @ilo.krafts
**Use this every single batch filming session. Zero skipped steps.**

---

## BATCH FILMING PHILOSOPHY
Film 7 videos in one session, once a week.
This gives you a full week's buffer so you never post under pressure.
Block 2–3 hours. Sunday or Monday works best — content is ready before the week starts.

---

## PHASE 1 — PREP (Night Before Filming)

### Content
- [ ] Pull up `month1-content-calendar.md` — identify the 7 videos for this week
- [ ] Read each script out loud once (cold read catches awkward lines)
- [ ] Adjust any language that doesn't sound like you naturally talking
- [ ] Write down the hook for each video on a sticky note — keep it visible while filming
- [ ] Identify which videos need vendor clips/product shots vs. which you film solo

### Props & Products
- [ ] Pull all products needed for this week's videos
- [ ] Clean products — no fingerprints, no dust (macro shots are unforgiving)
- [ ] Gather any raw materials, packaging, or props mentioned in scripts
- [ ] Prepare flat lay background (clean surface: marble contact paper, linen, or wood board)
- [ ] Wrap or package one item for the unboxing video (if applicable this week)

### Location
- [ ] Pick your filming spot — consistent background builds brand recognition
- [ ] Check background: nothing distracting, nothing branded that you don't want
- [ ] Test lighting in that spot at the time you plan to film

---

## PHASE 2 — SETUP (First 15 Minutes of Session)

### Lighting
- [ ] Natural light: Film near a window, light source in FRONT of you (not behind)
- [ ] Ring light: Position at eye level or slightly above, 2–3 feet away
- [ ] Overhead softbox: Diffused, positioned 45 degrees to the side for depth
- [ ] No harsh shadows on the product — if you see a shadow, move the light or add a reflector (white foam board works)
- [ ] Test: Take one photo of your product. If it looks good in the photo, it'll look good on video.

### Audio
- [ ] Quiet the room — turn off fans, AC, TV
- [ ] Close windows if there's street noise
- [ ] Test record 10 seconds of yourself speaking — listen back for echo or hum
- [ ] If echo: hang a blanket or towel behind you (soft surfaces absorb sound)
- [ ] Mic check: if using a lav mic, clip it 6 inches below your chin, hidden under shirt collar

### Camera / Phone
- [ ] Clean lens — wipe with microfiber cloth every session
- [ ] Charge battery to 100% before filming (or plug in)
- [ ] Clear storage: you need at least 10GB free for 7 videos
- [ ] Set to 1080p or 4K, 30fps (Settings → Camera)
- [ ] Turn on grid lines (helps with composition and keeping the phone straight)
- [ ] Airplane mode ON — no calls or notifications mid-take
- [ ] Mount phone in tripod/grip — no handheld unless the script calls for movement

### TikTok-Specific Settings
- [ ] Aspect ratio: 9:16 vertical ONLY
- [ ] If filming natively in TikTok: use the TikTok camera for direct editing
- [ ] If filming in your camera app: import to TikTok after (better quality)

---

## PHASE 3 — FILMING (The Session)

### Order of filming
Film in this order to minimize setup changes:
1. All videos with the same background first
2. All videos with the same product next
3. Process/tutorial videos last (more setup, more cleanup)

### For each video:
- [ ] Read the hook out loud before pressing record — lock it in your head
- [ ] Film at least 3 takes of the hook (the first 2 seconds) — you'll thank yourself in editing
- [ ] Film at least 2 takes of the full video
- [ ] For product shots: film 5–8 angles (top-down, side, close-up detail, in-hand, flat lay)
- [ ] For talking-head videos: film a "loose" version (relaxed, conversational) and a "tight" version (scripted, precise) — the loose one is usually better
- [ ] For tutorials: film each step individually, not in one continuous take — edit gives you control

### On-camera presence
- [ ] Speak to ONE specific person, not "everyone watching"
- [ ] Smile before you hit record — it carries into your voice even if you're not on camera
- [ ] Speak 20% slower than you think you need to — adrenaline speeds you up
- [ ] Pause after each sentence — silence before the next point = emphasis
- [ ] If you flub a line: stay still, count to 3, start that line again from the beginning

### Continuity notes
- [ ] If a product is in multiple videos this week: don't change its position between takes
- [ ] Wear the same outfit if videos will appear in the same week (subtle brand consistency)
- [ ] Keep the same text overlay style across all videos this week (same font, same color)

---

## PHASE 4 — EDITING

### Editing tool options (free or low-cost):
- **CapCut** — best for TikTok, free, has auto-captions, trending templates
- **TikTok native editor** — fast and simple, direct upload
- **InShot** — clean mobile editor, good for adding text overlays
- **Adobe Premiere Rush** — if you want more control

### Edit checklist for each video:
- [ ] Trim dead air at the start (video should start on the first frame of action/speech)
- [ ] Cut any pauses longer than 0.5 seconds between sentences
- [ ] Add captions (CapCut auto-caption: Settings → Captions → Auto-generate)
- [ ] Review captions for errors — fix any wrong words, especially brand names
- [ ] Add text overlay for the hook (appears on screen within first 2 seconds)
- [ ] Add any additional text callouts mentioned in the script
- [ ] Add trending audio OR voiceover — NOT both at the same volume
- [ ] If using voiceover + music: music at 20–30% volume, voice at 100%
- [ ] Color grade: slight brightness boost (+10) and saturation boost (+10) — products pop more
- [ ] Export at highest quality setting available
- [ ] Watch the full edit once before exporting — catch any jump cuts or awkward moments

### Final quality check before posting:
- [ ] First 2 seconds: does the hook work? Would YOU stop scrolling for this?
- [ ] Captions: readable, correct, contrasting color
- [ ] Audio: clear, no background hum, music not overpowering voice
- [ ] Product: in focus, well-lit, visible
- [ ] Video ends before or right as the CTA is delivered (no dead air at the end)

## PHASE 5 — POSTING

### Pre-post checklist:
- [ ] Caption is written and ready (from `caption-hashtag-templates.md`)
- [ ] 3–5 hashtags selected and copied
- [ ] CTA is the last line of the caption
- [ ] TikTok Shop product tagged (if product-feature video)
- [ ] Video scheduled for the correct day and time (see posting schedule)

### Posting window by day (EST):
| Day | Post Time |
|---|---|
| Monday | 7:00 PM |
| Tuesday | 12:00 PM |
| Wednesday | 6:00 PM |
| Thursday | 7:00 PM |
| Friday | 5:00 PM |
| Saturday | 11:00 AM |
| Sunday | 4:00 PM |

### After posting:
- [ ] Reply to every comment within the first 2 hours — this is non-negotiable
- [ ] Pin the most interesting comment (steers the conversation)
- [ ] Check analytics at 24 hours: note views, watch time %, likes, saves, shares
- [ ] Log the numbers in your Content Performance Tracker (in the content calendar)

---

## PHASE 6 — WEEKLY REVIEW (Every Sunday, 15 minutes)

Pull these numbers from TikTok Analytics for each video posted this week:

| Metric | What it tells you |
|---|---|
| Average watch time % | Hook strength — below 40% = hook needs work |
| Views | Reach — how many new people saw you |
| Follower change after video | Whether content converts viewers to followers |
| Saves | Value signal — people bookmark useful content |
| Shares | Virality signal — people send shareable content |
| Comments | Community signal — did you spark conversation? |
| Profile visits | Click-through — did they want to know more? |

**Weekly decision:** Which video type got the highest save rate this week?
Write it down. Do more of it next week.

---

## QUICK TROUBLESHOOTING

| Problem | Fix |
|---|---|
| Video looks dark | Add more light in front of subject, not behind |
| Audio has echo | Add soft surfaces — hang a blanket, record in a closet |
| Product looks flat | Add a second light source at 45 degrees |
| Video feels slow | Cut pauses between sentences. Target 100+ words per minute. |
| Low views despite good content | Hook isn't working — test 3 different hooks on the same content |
| High views, low follows | Video is entertaining but doesn't communicate WHO you are — add brand identity |
| High follows, low shop clicks | CTA isn't clear or compelling — make the ask more specific |
| Sudden drop in views | Check: posting consistency, any guideline strikes, trend cycle ended |
